How the scores get here

The container fetches the bridge GET /api/highscores feed and writes scores.json next to this page. This page loads that file on open and checks again every 30 seconds.

# docker-compose.yml · Dockhand stack: vpx-score-board
# Set VPIN_BRIDGE_URL and VPIN_API_KEY in the stack environment.
# The fetcher writes scores.json into the same folder nginx serves.
services:
  vpx-score-board:
    image: nginx:alpine
    container_name: vpx-score-board
    restart: unless-stopped
    ports:
      - "8745:80"
    volumes:
      - /DATA/AppData/vpx-score-board:/usr/share/nginx/html:ro
  scores-fetcher:
    image: alpine:latest
    container_name: vpx-score-fetcher
    restart: unless-stopped
    volumes:
      - /DATA/AppData/vpx-score-board:/data
    command: >-
      sh -c "while true; do
      wget -qO /data/scores.json.tmp --header='X-Api-Key: $$VPIN_API_KEY'
      $$VPIN_BRIDGE_URL/api/highscores
      && mv /data/scores.json.tmp /data/scores.json || true;
      sleep 30; done"
    environment:
      - VPIN_BRIDGE_URL=${VPIN_BRIDGE_URL}
      - VPIN_API_KEY=${VPIN_API_KEY}
Scores come from scores.json, produced from the vpin-bridge high-scores feed. If that file is missing or empty, this page shows “No scores yet” instead of inventing numbers.
